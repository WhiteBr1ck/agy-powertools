## 主な機能

- **多言語 UI**: Powertools パネル、Antigravity の主要メニュー、権限ダイアログ、設定画面、Swarm iframe を多言語化します。チャット本文やコードブロックには手を加えません。
- **コンテキストと速度テレメトリ**: 入力欄横にコンテキスト使用量リング（キャッシュ再利用、圧縮回数、Orchestrator 計画 / 実行バー付き）と速度メーター（`tok/s`、TTFT、モデル時間とツール時間の比較、セッション推定費用）を追加し、サブエージェント統計にも対応します。
- **ローカル使用量とリクエストダッシュボード**: デスクトップと `agy` CLI の使用量を統合する `Powertools` サイドバーページを追加します。使用量概要（53週間ヒートマップ、トークン / 費用ドーナツグラフ、モデル統計表）、リクエストログ、短時間キャッシュ異常フラグ、エラーのワンクリックコピー、クォータ推定、公式 API 料金の更新を備えています。
- **コンパクトレイアウトと段階的な進捗報告**: クライアントのフォントサイズを維持しながら行間とブロック余白を引き締めます。複数ステップのツール実行中は短い進捗をリアルタイム表示し、完了後は上部の所要時間ヘッダーへ折りたたみます。
- **会話の分岐とインライン編集**: 任意の回答や会話メニューから全履歴を保持したまま新しいチャットへ分岐でき（サブエージェントを使用した会話にも対応）、送信済みメッセージはその場で Antigravity 標準の入力欄を開いて編集と再生成を行えます。
- **マルチアカウント切り替え（既定オフ）**: Windows 資格情報マネージャー、macOS キーチェーン、Linux Secret Service を用いて平文トークンを保存せず複数の Google アカウントを分離管理します。サイドバーから5時間上限と週間上限を確認して切り替えられ、枯渇時の自動切り替えも設定できます。
- **非 TUN アプリ専用プロキシ（既定オフ）**: 再起動時に Antigravity のみへプロキシ引数と環境変数を注入します。HTTP CONNECT / SOCKS5 接続テスト、コールドスタート時の再起動案内、`EOF` 切断を軽減する `GODEBUG=http2client=0` に対応します。
- **SSH リモートと WSL2 対応**: サーバー側に何もインストールせず、ローカルの OpenSSH 経由でデスクトップ `SSH` ウィンドウのリモートセッション、サブエージェント、ダッシュボード統計を取得します。Windows 版 Antigravity と組み込み WSL2 バックエンドの NAT / Mirrored ネットワーク、ハイブリッド認証情報ストレージ、再起動委譲にも対応します。
- **ファイル右クリックメニューと便利機能**: ファイルリンクやファイルツリーを右クリックしてチャット添付、開く、フォルダ表示、ファイルコピー、パスコピー（Windows の LAN NAS / SMB パス含む）を行えます。折りたたみ可能な概要のタスク進捗とクォータ、タイトルバー未読件数、任意の入力欄クォータリング、任意のユーザー吹き出し着色も追加します。

## インストール

> 動作要件: Antigravity をインストールし、最低1回起動済みであること。ローカルの Node.js `>= 22.13` または Antigravity 同梱の `agy-node` を使用します。`npm install` や管理者権限は不要です。

### 方法 1: エージェントにインストールを任せる（推奨）

Antigravity またはローカルのコーディングエージェントに次のプロンプトを送信します:

> https://github.com/WhiteBr1ck/agy-powertools から Agy Powertools をインストールしてください。まず README_EN.md と docs/INSTALL_AGENT.md を読み、ローカルの Node.js または Antigravity 同梱ランタイムを使ってプロジェクト提供の統合インストーラーを実行してください。他のプラグイン、アカウント設定、チャット履歴はすべて維持し、実行中のクライアントを強制終了しないでください。完了後にインストール済みバージョンを確認し、再起動が必要なら案内してください。

詳細は [エージェント向けインストールガイド](./INSTALL_AGENT.md) を参照してください。

### 方法 2: コマンドライン

[Releases](https://github.com/WhiteBr1ck/agy-powertools/releases) から最新の ZIP をダウンロードして展開（またはリポジトリをクローン）し、以下を実行します:

```powershell
# Windows (PowerShell)
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

```sh
# macOS / Linux / WSL2
sh ./install.sh
```

再インストール時も保存済み設定は維持され、Antigravity を強制終了することはありません。現在の作業が終わったら Antigravity を再起動すると、左サイドバーに **Powertools** が表示されます。macOS では複製 `.app` ランチャーを作成せず、元の `Antigravity.app` を開いた際に必要な場合のみデバッグフラグ付きで1回自動再起動します（ループ防止機能付き。設定または「プラグイン -> Powertools」からいつでも手動再起動へ切り替え可能）。

### アップデートとアンインストール

- **アプリ内アップデート**: **Powertools -> 設定 -> 情報 -> アップデートを確認** から **アップデートをインストール** をクリックします。パッケージは SHA-256 で検証され、起動失敗時は自動ロールバックします。
- **アンインストール**: `powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1`（Windows）または `sh ./uninstall.sh`（macOS / Linux / WSL2）を実行します。`--keep-settings` を付けると設定を残せます。標準の会話履歴、アカウント、他のプラグインには影響しません。

## 設定

すべての設定は **Powertools -> 設定** で即時反映され自動保存されます（最下部に **デフォルトに戻す** があります）。

### インターフェースと表示

| 設定項目 | 既定値 | 説明 |
| --- | --- | --- |
| Powertools を有効化 | オン | マスタースイッチ。保存済み設定を保持したまま全 UI 拡張を一時停止します |
| 言語 | `簡体字中国語` | 9言語からインターフェース表示言語を選択します |
| ローカルフォントと太さ | クライアント既定 | ローカライズ名またはファミリー名で検索して適用します。太さは個別に指定でき、リセットで両方既定に戻ります。内蔵ターミナルはクライアントフォントを使用します |
| コンパクトレイアウト | オン | クライアントのフォントサイズを維持したまま行間 (`1.4`)、ブロック余白、ツール行を引き締めます |
| ユーザーメッセージの吹き出しを着色 | オフ | ユーザーメッセージに淡い背景色と枠線を付けます（アクセント、5種プリセット、カスタム色、10%-100% ブレンドスライダー） |
| 会話アウトラインを常に表示 | オン | 複数ターンの会話でターン移動ナビゲーションを常時表示します |
| チャット切り替え時に概要パネルを維持 | オン | 会話を切り替えても右側概要パネルの開閉状態を保持します |
| プロジェクトごとの表示会話数 | `デフォルト (6)` | サイドバーで各プロジェクトに表示する会話数（`デフォルト (6)`、`1-10`、または `すべて表示`） |
| サイドバーへのフォルダドロップ | オン | ローカルウィンドウでフォルダをサイドバーにドロップしてプロジェクトを作成または開きます |
| ドロップしたプロジェクトを自動ピン留め | オフ | フォルダドロップで作成または開いたプロジェクトを自動でピン留めします |
| サイドバー実行中ボーダービーム | オフ | サイドバーの実行中チャット外周に滑らかな光条を描画します（入力欄配色連動または個別選択、4点スピナー非表示、ライブプレビュー、確認待ち時のアンバー表示に対応） |
| サイドバー実行中会話グループ | オフ | サイドバー上部に折りたたみ可能な実行中グループを固定表示し、進行中の会話、プロジェクト、サブエージェント、確認待ち通知を一覧化します（待機時は自動非表示） |
| タスクバーの未読バッジ | オン | バックグラウンド会話完了時にウィンドウとタスクバータイトルへ `(N)` の未読件数を表示します |
